# YYYY-MM-DD: short title

Status: draft | reviewed
Sources: where the facts come from (commits, code, owner recollection).

## Summary
Two or three sentences: what broke, for whom, how it ended.

## Impact
Who and what was affected, for how long. Say "unknown" rather than guess.

## Timeline
Dates (and times only if known). Mark owner-supplied facts as such.

## Root cause
What actually failed, and how confident we are (confirmed / likely / unconfirmed), with the evidence.

## Detection
How it was found, and how long it took. What should have caught it.

## Fixes
What changed, with commit hashes. Say which fixes have a regression test and which do not.

## Lessons
What the incident showed about the system or the process.

## Follow-ups
Open items, each with an owner or "unassigned".
